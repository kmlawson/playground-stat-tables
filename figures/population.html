How these figures were gathered. Every figure on this page is a cell of one of the site's transcribed tables, exactly as transcribed. Agents first worked out, table by table, which rows and columns hold counts of people or households for a place and a date; a script then took the figures from the tables. Nothing has been re-read, corrected, averaged or filled in. The same figure printed in several tables is shown once, with a link to each table; different figures for the same place and year are shown side by side, with the gap between them.

A year comes from the table (its title, column heads, row labels or notes). Where a table gives no date the edition year of the book is used and the figure is marked “date not stated” (hollow dot). Figures printed in thousands (or with a point for the comma) are multiplied out, and the figure as printed is shown beside them (“printed 19,523, in thousands”), so it can be found in the table. Places are matched to a gazetteer by the names printed in the tables; the printed name is shown with each figure. Matching and dating were done by machine and may be wrong: always check the table, and the original scan linked from it.

Warning: These tables were transcribed by the vision models of Opus 5.5, Sonnet 5.5, or Haiku 5.5 (named on each book's page), and the figures on this page were gathered from them by machine. Before using any of these figures, you must verify specific statistics with the original source which is linked to whenever possible.
Each table can be downloaded as CSV from its page. Each book can be downloaded whole as an Excel workbook (one sheet per table, with a linked contents sheet) or as JSON; directories are available as Markdown.
