Find figures

Each of these pages gathers one kind of figure from every table on the site, place by place and year by year. Where several tables print the same figure it is shown once, with a link to each table; where they disagree, the figures are shown side by side.

PopulationPopulation figures for every country, colony, prefecture, province, city and district in the tables, year by year, with the contradictions kept and a link to each source table.127,535 figures from 1,553 tables · 8,790 places
Warning: These tables were transcribed by the vision models of Opus 5.5, Sonnet 5.5, or Haiku 5.5 (named on each book's page), and the figures on these pages were gathered from them by machine. Before using any of these figures, you must verify specific statistics with the original source which is linked to whenever possible.
Each table can be downloaded as CSV from its page. Each book can be downloaded whole as an Excel workbook (one sheet per table, with a linked contents sheet) or as JSON; directories are available as Markdown.
