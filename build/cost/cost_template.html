How the figures were made

  • Source. The local Claude Code session logs of this project, : sessions and sub-agent launches. Earlier logs no longer exist, so books published before show only later fixes and additions (marked before logs), and books that were under way when the surviving logs begin are marked partly before logs: their totals are too low.
  • Main session. Priced exactly from the usage recorded for every turn. Each turn is assigned to the book named in it (folder, site slug or NDL item number), otherwise to the book last named in the same session; after each new request from the user the assignment starts again. Turns before any book is named go to “Site-wide and other work”.
  • Sub-agents. Assigned to the book named in their instructions. agents' own logs survive and are priced exactly. For the other only the final context size (F) and number of tool calls (N) survive, from their completion notices; their cost is estimated with ratios fitted on the agents whose logs survive: . Checked against those agents, single estimates fall within about ±25%; book totals, which add up many agents, are closer. agents that were stopped or never reported have no record and are not counted.
